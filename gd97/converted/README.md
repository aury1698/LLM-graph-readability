# GD97 Converted

Exported to PNG using yEd, from the generated GraphML files.

**Make sure to enable File > Preferences > Display > Paint Nodes over Edges**

Export settings:
- Format: PNG
- Size: Custom Width
- Custom Width: 1024px
- Margin: 15
- Region: Complete Diagram
- Scaling Factor: 1.0
