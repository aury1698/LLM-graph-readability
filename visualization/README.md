# Instructions for accessing statistics

Run a server in the root folder of the project - the entire root, not just the visualization folder. 
The easiest way is to do it in python, running in your terminal

```
python3 -m http.server
```

then navigate with your browser to 

```
127.0.0.1:8000/visualization/visualization.html
```
or to:
```
127.0.0.1:8000/visualization/charts_visualization.html
```
